智能客服系统：Mermaid 流程图 + ER 图

Mermaid 库文件已下载到本地 cdn/mermaid.min.js（v10.9.1），以相对路径引入，离线渲染。图表源码直接写在 HTML 的 <pre class="mermaid"> 标签中。

① 智能客服问答流程图（Flowchart）

用户提问经意图识别分流：常见问题走知识库 RAG 检索作答，复杂问题转人工坐席。

flowchart TD
    A[用户发起提问] --> B[接入层 API 网关]
    B --> C{意图识别 NLU}
    C -->|常见问题| D[知识库检索 RAG]
    C -->|复杂 / 投诉| H[转人工坐席]
    C -->|办理业务| I[调用业务接口]
    D --> E[LLM 生成答案]
    E --> F{置信度足够?}
    F -->|是| G[返回答案]
    F -->|否| H
    I --> G
    H --> J[人工解答]
    J --> G
    G --> K[满意度评价]
    K -->|满意| L[写入知识库沉淀]
    K -->|不满意| M[标记待优化问答对]
    L --> N([会话结束])
    M --> N

② 智能客服数据库 ER 图（Entity Relationship）

五张核心表：用户、会话、消息、知识条目、工单，及其主外键关系。

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    SESSION ||--o{ TICKET : "可转人工生成"
    USER ||--o{ TICKET : "所属"
    KB_ENTRY ||..o{ MESSAGE : "被检索引用"

    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar channel "来源渠道"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        varchar status "进行中或已结束"
        datetime started_at "开始时间"
        int satisfaction "满意度评分"
    }
    MESSAGE {
        bigint msg_id PK "消息ID"
        bigint session_id FK "所属会话"
        varchar role "user或bot或agent"
        text content "消息内容"
        bigint kb_id FK "引用的知识条目"
        datetime sent_at "发送时间"
    }
    KB_ENTRY {
        bigint kb_id PK "知识条目ID"
        varchar title "问题标题"
        text content "标准答案"
        vector embedding "语义向量"
        datetime updated_at "更新时间"
    }
    TICKET {
        bigint ticket_id PK "工单ID"
        bigint session_id FK "来源会话"
        bigint user_id FK "所属用户"
        bigint agent_id "坐席ID"
        varchar status "处理状态"
    }
说明：使用 mermaid.initialize({ startOnLoad: true }) 自动渲染页面内所有 pre.mermaid 源码块； 流程图用 flowchart TD 语法，ER 图用 erDiagram 语法（PK/FK 标注主外键）。 与 ECharts 不同，Mermaid 是"文本即图形"——改源码即可改图，适合文档驱动开发。
