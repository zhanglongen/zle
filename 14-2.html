JavaScript 六种基本数据类型

原始类型（Primitive Types）：String、Number、Boolean、Undefined、Null、Symbol。下面的值与类型均由页面中的 JavaScript 实时计算得出。

说明：前五种是最常用的基本类型；Symbol 是 ES6 新增的原始类型，每个 Symbol 值都是唯一的。 另外，typeof null 的结果是 "object"，这是 JavaScript 早期遗留的历史问题，但 null 本身属于基本数据类型。 除这六种原始类型外，对象（Object）属于引用类型，不在本页演示范围内。
