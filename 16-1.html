JavaScript 数组方法可视化演示

数组是最常用的数据结构。下面把数组画成一个个彩色方块，点击按钮就能直观看到每种方法如何增、删、查、转数组元素；最后附一张全部主要方法的速查表。

体验台：把数组看成一行方块

绿色按钮在两端添加、红色删除、紫色查找（不改变原数组）、蓝色转换。每次操作后都会重画下面的方块并记录到日志。

map / filter / reduce：用条形图看变换

每个数字画成一根柱子。map 让所有柱子一起变高，filter 只留下偶数柱子，reduce 把所有柱子合并成一个总和。

当前数组：[5, 3, 8, 1, 4, 9, 2, 7]

速查表中的示例统一使用数组 var zle_demo = [3, 1, 4, 1, 5] 计算，结果由页面实时求出； 会修改原数组的（push、pop、shift、unshift、splice、reverse、sort）都先复制再演示。
