JSON 数据展示与解析

JSON（JavaScript Object Notation）是一种轻量级数据交换格式。本页展示 JSON 的结构、格式化高亮显示，以及 JSON.stringify 与 JSON.parse 的互相转换过程。

什么是 JSON？概念

JSON 使用键值对保存数据，支持字符串、数字、布尔值、null、数组和嵌套对象。语法与 JavaScript 对象字面量相似，但键名必须用双引号包裹。

{ "name": "张珑恩", "age": 20, "isStudent": true, "courses": ["HTML", "CSS", "JavaScript"] }

本地 JSON 文件思路扩展

实际项目中，JSON 数据通常来自服务器或本地 .json 文件，使用 fetch 读取后再用 JSON.parse 或 .json() 方法解析。

fetch('data.json') .then(zle_r => zle_r.json()) .then(zle_data => { console.log(zle_data); });
小结：JSON 是网页与服务器之间最常用的数据格式。通过 JSON.stringify() 可以把对象变成字符串便于传输；通过 JSON.parse() 可以把字符串还原为对象便于在页面中渲染。本页所有类名、id 与变量名均以 zle_ 开头。
