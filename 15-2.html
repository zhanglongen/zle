JavaScript 程序结构：条件与循环

程序的三种基本结构是顺序、条件（分支）和循环。本页用六张卡片演示条件语句（if / switch）与循环语句（for / while / do…while / for…of、for…in），运行结果均由页面实时计算。

if / else if / else条件

输入一个分数，程序按区间判断等级。试试 95、85、72、59。

if (zle_score >= 90) { ... } else if (zle_score >= 80) { ... } else if (zle_score >= 60) { ... } else { ... }

switch条件

根据今天的日期匹配星期几，适合多个等值分支的场景。

switch (zle_day) { case 1: zle_name = "星期一"; break; ... default: zle_name = "周末"; break; }

for 循环循环

循环次数已知时最常用：计算 1 + 2 + … + 100。

var zle_sum = 0; for (var zle_i = 1; zle_i <= 100; zle_i++) { zle_sum += zle_i; }

while 循环循环

先判断再执行：不断翻倍，直到超过 1000 为止。

var zle_num = 1; while (zle_num <= 1000) { zle_num *= 2; }

do…while 循环循环

先执行一次再判断，循环体至少运行一次。

var zle_k = 1; do { zle_list += zle_k + " "; zle_k++; } while (zle_k <= 5);

for…of 与 for…in循环

for…of 遍历数组的值，for…in 遍历对象的键。

for (var zle_f of zle_fruits) { ... } for (var zle_key in zle_student) { ... }

小结：if 适合区间判断，switch 适合等值匹配；for 用于已知次数，while 用于未知次数， do…while 保证至少执行一次，for…of / for…in 分别面向可迭代对象与对象属性。 本页所有变量、id 与类名均以 zle_ 开头。
